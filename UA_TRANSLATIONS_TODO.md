# Украинские переводы — что вставить в Shopify Admin

**Куда вставлять:** Shopify Admin → Settings → Languages → напротив "Українська" нажать
"Manage" → в поиске найти нужный товар по названию → открыть → вставить текст в
соответствующее поле (Title / Description / SEO title) → Save.

Это не может сделать я — переводы товаров хранятся в системе Shopify (Translate &
Adapt), а не в файлах темы, доступа к Admin API у меня нет и не должно быть.

## 3. СТРУКТУРНЫЙ БАГ — исправить, не переводить заново

### Coin Ring (`coin-ring`)

Сейчас в поле **Title** стоит вся SEO-фраза целиком:
> Каблучка Coin — срібна каблучка ручної роботи | BROQ

Это должно быть в поле **SEO title**, а не в **Title**. Исправление:

**Title (заменить на короткое):**
```
Каблучка Coin
```

**SEO title (оставить как есть, это поле уже правильное):**
```
Каблучка Coin — срібна каблучка ручної роботи | BROQ
```

**Description — грамматика:** "виготовлений вручну" → "виготовлен**а** вручну"
(каблучка — женский род, сейчас согласование неверное).

## 4. НЕСОГЛАСОВАННОСТЬ ТЕРМИНОВ: "Кафф" vs "Кафа"

На сайте вперемешку используются два разных украинских слова для "cuff":

| Товар | Сейчас | Исправить на |
|---|---|---|
| earcuff-1-0 | Кафф 1.0 | ✓ уже верно, ничего не трогать |
| **earcuff-2-0** | **Кафа 2.0** | **Кафф 2.0** |
| earcuff-4-0 | Кафф 4.0 | ✓ уже верно |
| infante-ear-cuff | Кафф Infante | ✓ уже верно |
| infante-neo-ear-cuff | Neo ear cuff (англ.) | Кафф Neo (см. выше) |

## 6. ОТДЕЛЬНО (не перевод, но нашла заодно)

Эти товары показывают покупателю голый внутренний артикул вместо названия — **на
обоих языках**:

- `bq_4`, `bq_11`, `bq_8`, `bq_2`, `bq_1` → заголовок = "bq_4" / "bq_11" и т.д.
- `bq_u01` → заголовок = "bqSS24_1"

Я не могу придумать за тебя человеческое название для этих украшений (не видела их
вживую/в деталях) — но раз уж будешь в Admin, стоит одновременно дать им нормальные
имена на обоих языках. Скажи, как называются эти модели — переведу сразу.
